# 🌌 NASA APOD - Cyberpunk Astronomy Explorer

An interactive web application built with **Vite** and **JavaScript** that fetches and displays NASA's **Astronomy Picture of the Day (APOD)**. Featuring custom cyberpunk styling, dynamic date selection via an interactive calendar, responsive video/image handling, and neon clip-path side borders.

---

## ✨ Features

- **Daily Space Discoveries:** Automatically fetches today's NASA APOD on load.
- **Interactive Calendar Picker:** Select any past date to view historical astronomy photos or videos.
- **Dynamic Media Support:** Automatically renders images, YouTube embedded videos, or direct HTML5 video files.
- **Cyberpunk UI Design:** Custom Google Fonts (`Orbitron` and `Black Ops One`), neon glow effects, and responsive zigzag `clip-path` side borders.
- **Secure Key Management:** Uses environment variables (`.env`) for NASA API keys with a failover fallback.
- **Automated Deployment:** Integrated with GitHub Actions to publish updates straight to GitHub Pages.

---

## 🛠️ Tech Stack

* **Build Tool:** [Vite](https://vitejs.dev/)
* **Languages:** JavaScript (ES6+), HTML5, CSS3
* **API:** [NASA APOD API](https://api.nasa.gov/)
* **Fonts:** Google Fonts (*Orbitron*, *Black Ops One*)
* **Deployment:** GitHub Pages & GitHub Actions
