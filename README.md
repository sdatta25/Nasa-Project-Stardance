# NASA APOD Space Explorer

Hey! This is my Astronomy Picture of the Day app built with Vite and vanilla JavaScript. I built this to browse cool space pictures and learn how to handle third-party APIs.

## What it does
- Pulls NASA's daily picture or video using their official APOD API.
- Has a calendar date picker so you can check out photos from any day back to 1995.
- Works with both space photos and YouTube/video embeds.
- Includes a randomizer button to jump to a surprise day in space history.

## Built With
- Vite + JavaScript
- CSS3
- NASA APOD API

## Running locally
1. Clone this repo
2. Run `npm install`
3. Run `npm run dev`
4. Add your API key in a `.env` file (`VITE_NASA_API_KEY=your_key`)
